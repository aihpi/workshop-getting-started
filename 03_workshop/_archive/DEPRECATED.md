# DEPRECATED — Pre-May 2026 Setup Guides

> **These materials are kept for reference only.** They reflect the workshop format used **before May 2026**, in which participants worked through long, OS-specific setup scripts step by step.

The workshop has since been reworked into an more **interactive format** organised around the individual tools (VSCode, WSL, Git, Python, UV, Ollama, Docker) rather than the operating system. Each tool now has its own short guide that explains *what* it is, *why* it is used, and how to install and try it — with the live session focused on understanding rather than mechanical execution.
